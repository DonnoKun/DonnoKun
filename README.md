## 🚀 Currently Building: EduAccess

<table>
<tr>
<td width="58%" valign="top">

**A hybrid SOA + microservices platform that automatically remediates accessibility issues in educational content, powered by resilient AI services.**

- 🧩 **SOA governance + microservices deployment**: reusable services, independently shippable units
- 🛡️ **Resilience4j everywhere**: Circuit Breaker, retries, fallbacks and multi-provider AI adapters, so one provider going down never takes the system with it
- 📨 **Event-driven** processing over Apache Kafka
- 🤖 **AI services**: image captioning (ViT-GPT2), chart and diagram description, OCR, text-to-speech
- ✅ **Automated WCAG conformance checks**
- 🐳 Containerized with **Docker**, orchestrated on **Kubernetes**
- 🧪 Validated with **fault injection** and architecture evaluation (ATAM)
