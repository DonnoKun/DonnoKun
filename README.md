## 🔬 Flagship Project: EduAccess

<table>
<tr>
<td width="60%" valign="top">

**Hybrid SOA + microservices architecture for automatic accessibility remediation in educational content, powered by resilient AI service integration.**

Target users: students with mild to moderate visual impairment.

- 🧩 **SOA as the paradigm, microservices as the strategy**: reusable governed services, independently deployable units
- 🛡️ **Resilience first**: Circuit Breaker, retries and multi-provider adapters so an AI outage never takes the system down
- 🤖 **AI assistive services**: image description (ViT-GPT2), OCR, text-to-speech
- ✅ **Automated WCAG conformance verification**
- 📐 **Formally specified** with UML, SoaML, BPMN and CTT
- 🧪 **Evaluated** via fault injection, ATAM with experts and usability testing with end users
